# The Tide Mother — Video Prompts for Grok Imagine (15-second beats)

*112 image-to-video prompts, 15 s each. Each one is time-coded (0–5 s / 5–10 s / 10–15 s), so Grok Imagine paces the action across the whole clip. Dialogue is spoken once, in the beat where it appears in the script, with a voice description so Grok's native audio matches the character.*

**How to use in Grok Imagine**
- Upload the matching image beat, choose **Make video**, set **16:9** and **15 s**, and paste the video prompt.
- Use the **Normal** mode, not Spicy or Fun. The mob and cliff scenes are written to stay within moderation.
- If a clip drifts (a face or the dragon changes), regenerate from the same image. Don't chain from the last frame, because every beat has its own start image.
- Grok renders spoken lines best when each line is short and attributed to a visible speaker. Lines are already split that way.
- If your plan only allows shorter clips, generate 0–10 s and use **Extend** with the 10–15 s part of the prompt.

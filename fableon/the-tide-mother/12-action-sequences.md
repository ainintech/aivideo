# Action-State Sequences for Grok Frame-to-Video

*Every beat where a character handles an object or touches another character is broken into its physical action states. Each state has its own start image and its own 6-second video that continues forward from that exact state. Extra states keep the beat number with a letter (022, 022b, 022c), so existing beat numbers never change.*
